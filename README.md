# Keepsy

用数据线把 iPhone 上的原片和视频，落到你选定的文件夹。文件名和内容不变。软件里的相册不搬动这些文件。

## 下载

[Keepsy v1.0.1（Windows 64 位）](https://github.com/ballmaK/keepsy-download/releases/download/v1.0.1/Keepsy-v1.0.1-win-x64.zip)

解压后运行 `Keepsy.exe`。.NET 已在包内，不用单独安装。需要 Windows 10 或 Windows 11。

用数据线连上 iPhone，解锁，并在手机上信任这台电脑。

## 限制

- 只拷手机里已经有的文件。还在 iCloud、没下载到手机里的不会出现。
- 不转码。HEIC 和 HEVC 能否打开取决于 Windows 自己的解码器。
- Live Photo 不单独还原。
- 关掉软件后，这次没传完的明细不保留。已经传完的文件还在。

读取 iPhone 需要这台电脑上已经安装的 Apple 移动设备支持。Keepsy 不附带那个安装包。
